# RimLazy 0.3.0 验收

2026-11-12，Windows，RimWorld 1.7.5005 rev1082，Harmony 1.7 目录中的运行库。此版本在既有六档工作表和细分岗位上增加培养上限、单次赶工、任务评估与装备建议。

## 离线核心

32 项测试通过。测试对最终离散矩阵检查每个方向的当期表现。例子中一个熟手能做 100 单位、双火学徒能做 92 单位，5% 的容忍度保留熟手，8% 时学徒可以入选。覆盖赶工、零潜力、工时与任务覆盖、锁定、未知工作、有限订单、多人组合以及跨列共享工位。

默认环境还实测了下列行为。

- 用真实「分工」窗口预览常态和赶工。23% 培养设置在赶工中临时归零，赶工矩阵逐格等于当期参考矩阵。临时指定方向只影响剩余劳力；取消后拒绝应用过期预览，写回后仍保留原预设。
- 在测试殖民者身上读取真实的移动狂热属性。全天有效时速度与面板一致，半天剩余时只对一日预测中的一半计入增益。一次性交易收益从测算中移出，创作灵感不改变工作矩阵；预览保留灵感和游戏随机状态。
- 穿上带直接修正的测试厨师帽，常态参考移速和个人污染风险保持原值，赶工使用当前穿戴的实际污染概率。只有一顶库存帽、两名合格厨师时最多出现一条建议，餐单、储区和实际穿戴未被建议逻辑改动。
- 在隔离殖民地生成真实燃料灶、简单餐工单与食材。移动食材会改变路途占比与预计产出。原料半径、指定人、两份/四份需求和断燃料均产生相应效果。厨艺 4/9 的预计污染风险与游戏房间及个人实际 Stat 一致。同一张餐单上仅切换无火/双火，预计当期表现相同，培养收益发生变化。

## 估算边界

常态看接下来一个游戏日，赶工看一个游戏小时。作息及开放岗位使用代表工序，路线按有限数量的真实寻路样本和几何估计计算。工位、物料与订单可能在未来改变。自定义药品、手术后果及不透明的第三方属性来源存在估算误差。常态剥离能追踪的可转移装备偏移和光环直接属性；修改身体能力的光环或服装赋予的特性会留下不确定性。装备建议按已有工作量和可识别属性排序，只展示可行且互不冲突的候选，由玩家调拨。

该次验收覆盖工作页行为与数据，未进行图形排版目测或长期追踪实际生产工时。未用玩家日常存档做回归。
